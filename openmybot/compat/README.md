# Compatibility evidence

This directory is reserved for version-specific compatibility evidence as integrations are delivered. The accepted CrabCode versions are listed in [`crabcode/accepted.json`](crabcode/accepted.json): 1.1.16, recorded in [`crabcode/1.1.16.md`](crabcode/1.1.16.md). There are no accepted channel version claims, Feishu included; the real-channel recheck is pending with the owner. The Feishu long-connection wire protocol this project implements is recorded in [`feishu/long-connection.md`](feishu/long-connection.md); that record is not a version claim. The local daemon does not establish channel, model or MCP compatibility.
