## Deviations

| Deviation | Observation |
|---|---|
| `--` separator | The 1.1.16 launcher passes unknown flags to the CLI only after `--`; the driver places `--print` before `--` and the protocol flags after it |
| `--verbose` | With `--print` and `--output-format stream-json`, 1.1.16 exits 1 unless `--verbose` is present; carried in the entry's `extra_args` |
| Permissive user layer | With allow-all user settings 1.1.16 runs Write without `can_use_tool`; `permissions.ask` rules in the entry's `extra_args` restore the request (they take precedence over allow rules and modes) |

## Not covered

| Item | Reason |

| Read-only tool through `can_use_tool` | 1.1.16 allows Read inside the CLI; no `can_use_tool` request is emitted for it |
| MCP plugin tools | Their names depend on the owner's plugins and the `ask` rules carry no wildcard; only the 14 built-in tools listed above are covered |
| Launcher stderr spill | On a CLI start failure the launcher writes the CLI's stderr to the owner's CrabCode debug directory regardless of isolation; not exercised by the passing run |
